# Telemetry Forge App - AI Agent Directives & Rules

This directory configures the multi-agent AI framework rules for the autonomous Telemetry forge app submodule.

## Structure
- `AGENTS.md`: Canonical agent rules, invariants, and engineering standards for this micro-app.
- `rules/`: Modular sub-rule definitions covering security audits, code limits, Astryx UI tokens, and test governance.

## Directives
AI assistants interacting with this submodule must operate autonomously, maintaining absolute boundary isolation from the core platform services.
