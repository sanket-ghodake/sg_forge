# Strix Code Audit Skill (`strix-code-audit`)

This skill package equips AI agents with the **Mode 1: White-Box Source Code Review** capabilities of Strix.

---

## 🚀 Purpose
Enables AI coding agents to perform proactive, zero-API-key static & semantic security reviews on repository source files, enforcing OWASP ASVS 5.0, Enterprise SRE logging, and Enterprise AppSec invariants.

## 📌 Usage
In any pair programming session, invoke:
- `"audit code <path>"`
- `"/audit-code"`
- `"check security of auth routes"`
- `"strix code check"`
