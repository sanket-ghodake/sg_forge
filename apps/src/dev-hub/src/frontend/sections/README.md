# 📑 Developer Hub Modular UI Sections (`apps/src/dev-hub/src/frontend/sections/`)

Cohesive UI section renderers for the SG Forge Developer Gateway and SDK Hub.

---

## 📂 Section Modules

- **`overview-section.ts`**: Platform topology, reverse proxy routing matrix, and 10 engineering invariants.
- **`sdk-section.ts`**: Complete `@forge/sdk` reference, code examples across TS, Python, Go, and cURL.
- **`ui-section.ts`**: Astryx design system tokens (`--forge-*`), Astryx Toast overlays, custom styled controls.
- **`gateway-section.ts`**: Caddy ingress proxy, `.env` declarative app registration, and injected Zero-Trust gateway headers (`X-Forwarded-*`).
- **`scaffolding-section.ts`**: 1-command microservice generator (`./run.sh create-app`), Docker boilerplates.
- **`sandbox-section.ts`**: Live API sandbox runner, header simulator, and interactive endpoint inspector.
- **`testing-section.ts`**: 5-tier testing standard, 3A pattern, and quality gate verification commands.
