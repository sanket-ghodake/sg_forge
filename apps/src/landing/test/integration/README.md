# Landing Integration Tests

This directory contains Tier 2 integration test suites for `@forge/landing`.

## Suites
- `not-found-route.test.ts`: Validates 404 route defense and Astryx error rendering.
- `registry-sync.test.ts`: Validates portal and microservice registry synchronization.
- `offline-sw.test.ts`: Validates offline service worker delivery and local caching screens.
