## 2. Core Invariants

### 1. Single Source of Truth
* All UI component state is derived from immutable application stores defined in `@forge/ui/state`.
* State mutations are strictly dispatched through typed actions with payload validation.

### 2. Multi-Tab Synchronization
* State changes broadcast across browser tabs via the `BroadcastChannel` API (`forge_state_channel`), ensuring user actions in one tab reflect across all active sessions without a page reload.

### 3. Graceful Storage Degradation
* In private browsing mode or environments with restricted storage access, the client engine falls back cleanly to an in-memory storage dictionary without throwing uncaught exceptions.
