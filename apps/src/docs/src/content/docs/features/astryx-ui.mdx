## 1. Astryx Design Token Hierarchy

All user interfaces across core platform services and Forge submodules must strictly consume the modern Astryx token system (`@forge/ui`). Ad-hoc hex colors, inline margins, and random component libraries are strictly blocked by pre-commit verification.

## 2. Dynamic Viewport Collision Detection Engine

Native browser tooltips (e.g. `title="..."`) and unconstrained dropdown menus frequently clip against browser window edges. Architectural directive 4 mandates custom Astryx floating tooltips (`data-astryx-tooltip`) with smart collision detection.

### Collision Math & Positioning Algorithm
```typescript
export function computeTooltipPosition(
  triggerRect: DOMRect,
  tooltipRect: DOMRect,
  viewportWidth: number,
  viewportHeight: number
): { top: number; left: number; placement: 'top' | 'bottom' } {
  const GAP = 8;
  let placement: 'top' | 'bottom' = 'top';
  let top = triggerRect.top - tooltipRect.height - GAP;

  // Auto-flip downward if clipping against the top edge
  if (top < 0) {
    top = triggerRect.bottom + GAP;
    placement = 'bottom';
  }

  // Calculate centered horizontal coordinate
  let left = triggerRect.left + (triggerRect.width - tooltipRect.width) / 2;

  // Clamp horizontal coordinate inside viewport with 8px margin
  left = Math.max(8, Math.min(left, viewportWidth - tooltipRect.width - 8));

  return { top, left, placement };
}
```
