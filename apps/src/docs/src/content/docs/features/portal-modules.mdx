## 1. Portal Workspace Architecture

The **SG Forge Portal** (`@forge/portal`) operates on internal port `:3001` (proxied at `/portal`). It hosts 9 modular SPA views, the global keyboard navigation engine, and sandboxed micro-app iframes.

## 2. Key Subsystems & Ergonomics

### 1. Global Command Palette (`⌘K` / `Ctrl+K`)
- Omnipresent fuzzy-search modal accessible anywhere in the application.
- Supports keyboard navigation (Arrow Up/Down, Enter, Escape) to jump instantaneously to views, search team members, launch micro-apps, or trigger administrative actions.
- Automatically synchronizes with the active user's RBAC role to prevent unauthorized command execution.

### 2. 2D Interactive Semantic Org Canvas (`ui-canvas-views.ts`)
- High-performance vector canvas visualizing the organization's polymorphic hierarchy (Divisions, Departments, Squads, Employees).
- Interactive drag-and-zoom controls with materialized path calculations.
- Clicking any node opens the **Canvas Inspector** (`ui-canvas-inspector.ts`), displaying department metadata, direct reports, upward management chain, and assigned micro-apps.

### 3. Universal Notification Inbox (`inbox-service.ts`)
- Multi-channel notification center with unread count badges in the header bar.
- Streams operational alerts, task assignments, security warnings, and automated backup confirmations.
- Supports 1-click action drawers, item dismissal, and cross-tab state synchronization.

### 4. Admin Console & Governance (`ui-admin-*.ts`)
- **Member Management**: Role assignment (`super_admin`, `admin`, `manager`, `user`), status toggling, and department assignment.
- **App Permissions**: Fine-grained per-role and per-organization micro-app access control.
- **Audit Center**: Real-time event log with user IDs, timestamps, IP addresses, and RFC 7807 trace correlation.
