## 1. Network Topology Specifications

<TraceabilityBadge reqId="SR-SEC-001" type="SR" status="verified" />

The platform partitions networks into two distinct security zones:

* **Core Air-Gap Zone (`core-airgap-net`)**: Resides with `internal: true`. Central services (`portal`, `auth`, `dev-dashboard`) have zero internet gateway access.
* **Submodule Zone (`forge-apps-net`)**: Autonomous micro-apps (`forge-apps/code`, etc.) communicate with external webhooks directly without bridging to the core air-gap network.
