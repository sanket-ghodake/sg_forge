## 1. The 12 Non-Negotiable Invariants

The SG Forge architecture enforces twelve immutable principles of Enterprise SRE and Application Security standards:


1. **Correctness & "No Guessing"**: Zero hallucinated APIs, schemas, or dependencies.
2. **Strict File Size Governance**: Source files strictly capped at $\le 500$ lines.
3. **Astryx UI System**: 100% compliant with `@forge/ui` tokens; zero OS or browser defaults.
4. **Centralized Structured Logging**: RFC 7807 problem details with trace correlation and automated PII redaction.
5. **Multi-Tenant Data Isolation**: Dedicated Turso libSQL database instance per micro-app.
6. **Air-Gapped Core Platform**: `core-airgap-net` (`internal: true`) with zero outbound egress.
7. **Clean Package Aliases**: `@forge/sdk`, `@forge/ui`, `@forge/types` with zero relative traversal.
8. **5-Tier Test Architecture**: Unit, Integration, Security, Contract, and E2E tiers.
9. **Single-Location Dynamic Ingress**: Driven exclusively from `.env` via Caddy reverse proxy.
10. **Code Preservation & Worklog Ledger**: Standard header blocks and per-task worklog entries.
11. **In-Chat AI Security Auditor**: Strix white-box AST review and non-destructive live pentesting.
12. **Systems Traceability & Living Standards**: Bidirectional requirement tracking (`SR -> HLR -> LLR -> Code -> Test`) with 100% symbol coverage.
