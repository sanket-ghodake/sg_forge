## 1. Requirement Statement

1. All frontend views across the SG Forge platform and Forge Apps shall strictly utilize modern **Astryx design tokens** (`@forge/ui`) and CSS custom properties (`--forge-*`).
2. Operating system and browser default controls are **STRICTLY FORBIDDEN**:
   * Scrollbars must use slim, themed Astryx tracks.
   * Notifications must use Astryx Toast overlays.
   * Tooltips and popovers must use custom floating tooltips (`data-astryx-tooltip`) with zero OS `title` attributes.
   * Dialogs must use Astryx glassmorphic backdrop dialogs (zero native `alert()` or `confirm()`).
3. All dropdowns, flyouts, and tooltips shall implement dynamic viewport collision detection (auto-flipping upwards, shifting horizontally, or clamping max-height) to guarantee 100% visibility inside the active viewport window down to 320px width.
