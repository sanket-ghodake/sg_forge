## 1. Requirement Statement

1. All code changes across SG Forge and submodules shall pass the unified **29 Tier 1 deterministic checks** and **8 Tier 2 AI semantic audits** prior to staging or committing (`rtk ./run.sh verify`).
2. **Absolute Zero Auto-Commits**: AI agents are strictly blocked from running `git commit` unless the user explicitly commands it in the active prompt.
3. Every source file must adhere to the **500-line soft cap** ($\le 300$ ideal, $\le 500$ max).
4. Every conversation task completion must append strictly one entry to `logs/WORKLOGS.md`.
