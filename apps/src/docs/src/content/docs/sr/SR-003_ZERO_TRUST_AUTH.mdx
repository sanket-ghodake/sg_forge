## 1. Requirement Statement

1. All incoming requests to authenticated platform routes shall be secured by cryptographically signed HMAC-SHA256 session tokens stored inside HTTP-only, SameSite=Strict, Secure cookies (`__session`).
2. Authentication middleware shall enforce a sliding inactivity expiration window, clamped strictly between 300 seconds (5-minute floor) and 604,800 seconds (7-day ceiling).
3. Signature verification shall strictly utilize constant-time comparison to prevent timing side-channel analysis.
4. Token replay or refresh family reuse shall trigger immediate invalidation of the entire session lineage.

## 2. Verification Invariants

* **Cryptographic Strength**: HMAC-SHA256 with minimum 256-bit entropy secret (`JWT_SECRET`).
* **Maximum Clock Skew**: Tolerates $\le 60$ seconds clock discrepancy between distributed nodes.
* **Negative Assertions**: Tested in `apps/src/auth/test/security/token-replay.test.ts` with 100% branch coverage.
