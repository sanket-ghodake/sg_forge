## 1. Requirement Statement

1. All micro-applications in `forge-apps/*` shall operate as decoupled Git submodules maintaining their own standalone repositories, `.git` references, `Dockerfile`, `package.json`, and local agent directives.
2. AI agents and developers are **STRICTLY PROHIBITED** from importing code from central platform directories (`apps/src/*`) into `forge-apps/*`.
3. Forge Apps shall run on `forge-apps-net` with autonomous outbound egress permissions, managing local credentials, timeouts, and health probes independently.
