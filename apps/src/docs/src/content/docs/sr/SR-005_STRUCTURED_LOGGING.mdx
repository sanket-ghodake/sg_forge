## 1. Requirement Statement

1. All platform services, API routes, and micro-apps shall utilize `@forge/sdk` (`createLogger`, `createSafeHandler`) for observability and error handling.
2. Log outputs shall strictly format as single-line JSON objects complying with RFC 3339 UTC timestamps, severity level, service name, and immutable `traceId` correlation.
3. The logging engine shall perform automated recursive redaction on sensitive fields (`password`, `token`, `secret`, `authorization`, `creditCard`, `apiKey`).
4. HTTP error responses shall conform to RFC 7807 (`application/problem+json`) containing standard fields (`type`, `title`, `status`, `detail`, `instance`, `traceId`) with zero internal stack trace exposure.
