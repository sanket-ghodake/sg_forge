## 1. Requirement Statement

1. Every feature, microservice, and exported code symbol across the platform shall maintain strict bidirectional traceability:

```
System Requirements (SR) ⟷ High-Level Requirements (HLR) ⟷ Low-Level Requirements (LLR) ⟷ Source Code AST ⟷ 5-Tier Tests
```

2. Every exported TypeScript function, class, interface, and type shall declare an `@requirements [LLR-...]` TSDoc tag.
3. Automated AST scanning (`scripts/verify-doc-coverage.ts`) shall continuously audit symbol coverage, failing pre-commit gates on newly introduced unannotated exports.
4. The documentation web portal (`@forge/docs`) shall operate 100% offline with Pagefind WebAssembly search and zero cloud SaaS dependencies.
