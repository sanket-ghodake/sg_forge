## 1. Requirement Statement

The SG Forge Core Platform shall operate exclusively within an isolated Docker bridge network (`core-airgap-net`) configured with `internal: true`. Central services shall have no default route to external internet gateways.

## 2. Rationale & Systems Traceability

Under mission-critical distributed engineering standards, enterprise systems handling sensitive credentials and customer databases must prevent unintentional packet egress.
