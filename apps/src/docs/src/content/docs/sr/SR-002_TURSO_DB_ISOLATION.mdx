## 1. Requirement Statement

1. Every Forge Micro-App (`forge-apps/*`) and core platform service shall operate on its own dedicated Turso (libSQL) SQLite database instance residing in its local `data/` directory.
2. Micro-apps are **STRICTLY PROHIBITED** from establishing database connections, executing SQL queries, or reading raw SQLite files belonging to another micro-app.
3. Every database table containing tenant records shall enforce an immutable `org_id` foreign key column, validated on all read, write, and delete mutations.

## 2. Verification Invariants

```
∀ app_i, app_j ∈ ForgeApps (i ≠ j ⟹ DB(app_i) ∩ DB(app_j) = ∅)
```

* **Verification Method**: Automated AST SAST analysis (`scripts/verify-checks.ts` Check 21) verifying zero cross-app imports or query references.
* **Failure Handling**: Immediate RFC 7807 problem details response (HTTP 403 Forbidden) and security audit log entry.
