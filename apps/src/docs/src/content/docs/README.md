# SG Forge Documentation Content Structure

This directory houses living documentation pages structured according to SG Forge Living Standards (High-Reliability Systems, Modular C4, and Systems Engineering Standards):


* **Executive Briefings (`executive/`)**: Plain-English 30-second overviews for business and leadership.
* **System Requirements (`sr/`)**: High-level platform safety and architectural invariants.
* **High-Level Requirements (`hlr/`)**: Service-level functional specifications.
* **Low-Level Requirements (`llr/`)**: Algorithmic, error handling, and parameter specifications.
* **Submodule Documentation (`submodules/`)**: Independent Forge Apps (`code`, `telemetry`, `app-template`).
* **Traceability Matrix (`traceability/`)**: Bidirectional code-to-doc verification matrix.
