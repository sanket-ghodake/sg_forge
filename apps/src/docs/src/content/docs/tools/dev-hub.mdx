## 1. Architectural Role & Ingress

The **Developer Hub & SDK Playground** (`@forge/dev-hub`) serves on internal port `:3003` and is exposed via the reverse proxy at `/gateway`. It operates statelessly as a mesh client consuming `@forge/sdk` and central authentication services.

## 2. Eleven Core Sections & Capabilities

The Developer Hub UI is organized into 11 high-density, interactive sections:

1. **System Topology & Architecture Invariants**:
   - Interactive live view of Enterprise architectural standards enforced across the monorepo.
2. **Health Mesh Prober**:
   - 1-click **Ping All Services** trigger measuring microsecond round-trip latencies across all 8 registered microservices and micro-apps.
3. **Token Minting Sandbox**:
   - Instant 1-click test token generation for seeded platform personas (`superadmin@forge.internal`, `developer@forge.internal`, etc.).
   - Interactive JWT payload and claims inspector demonstrating Ed25519 asymmetric signature validity.
4. **Declarative Ingress Matrix**:
   - Real-time route inspector reflecting active reverse proxy upstreams dynamically parsed from `.env`.
5. **Polyglot Code Scaffolding Generator**:
   - Interactive multi-language starter generator delivering complete boilerplate code for **TypeScript / Bun**, **Python FastAPI**, and **Go Fiber**.
6. **SDK Interactive Playground**:
   - In-browser sandbox simulating `postMessage` iframe bridge handshakes, theme synchronization, and authenticated API requests.
7. **Security & RFC 7807 Matrix**:
   - Comprehensive error catalog detailing standard problem details (`application/problem+json`), HTTP status codes, and immutable `traceId` correlation.
8. **Testing Rigor & Pyramid**:
   - Live examples of 3A Pattern (Arrange, Act, Assert) unit, integration, and security tests.

## 3. Local Execution & Testing

```bash
# Run Dev Hub standalone server
rtk bun apps/src/dev-hub/src/server.ts

# Run Dev Hub 5-Tier test suite
rtk bun test apps/src/dev-hub/test
```
