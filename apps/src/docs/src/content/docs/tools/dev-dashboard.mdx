## 1. Architectural Role & Ingress

The **Developer Operations Dashboard** (`@forge/dev-dashboard`) serves on internal port `:3002` and is exposed via the gateway at `/devcenter`. Built to Enterprise SRE and Astryx enterprise standards, it houses 13,576 SLOC across high-density studio controllers, live streamers, and database diagnostics.

## 2. Core Operational Capabilities

### 1. Fleet Health Mesh & Vitals Probing
- Continuous background prober monitoring all 8 platform microservices and autonomous Forge Apps.
- Tracks dual-probe health endpoints (`/health/liveness` and `/health/readiness`).
- Renders responsive status cards with latency metrics and auto-recovery triggers.

### 2. Live SSE Log Streamer (`/api/logs/stream`)
- Employs an in-memory circular ring buffer holding the most recent 1,000 structured JSON log events.
- Streams live telemetry to the browser via Server-Sent Events (SSE) with **zero disk churn**.
- Transparently applies recursive PII redaction: sensitive credentials, JWT tokens, and passwords are automatically scrubbed before transmission.

### 3. Unified Database Studio & Remote Gateway
- **Schema Inspector**: Visual tree browser inspecting SQLite tables, foreign keys, and column types.
- **Fast Paginated Data Browser**: Safely paginates thousands of rows with sanitized table parameter filtering.
- **Monospace SQL Editor**: Enforces a `READ_ONLY` transaction sandbox, preventing accidental `DROP` or `DELETE` mutations.
- **Remote DB Gateway**: Connects securely to isolated microservice databases (`/api/db/connect`) for live debugging without leaving the browser.

### 4. Secrets Defense & Environment Variable Masking
- The `/api/env/safe` endpoint automatically detects sensitive keys (`PASSWORD`, `SECRET`, `KEY`, `TOKEN`).
- Sensitive values are replaced with bullet masks (`••••••••`), preventing credential exposure during screenshares or browser inspection.
