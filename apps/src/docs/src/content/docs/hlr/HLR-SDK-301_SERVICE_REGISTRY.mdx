## 1. Functional Specification

The Platform SDK (`@forge/sdk/registry`) shall parse all registered applications from `.env` via the standardized declarative ingress pattern:

```bash
APP_<ID>="<Display Name>|<Internal Port>|<Public Path>|<Category>|<Role>|[Upstream]"
```

1. Provides type-safe `loadServiceRegistry()` returning normalized `ServiceEntry` records.
2. Synchronizes Caddy reverse proxy routing (`scripts/generate-proxy.ts`) without manual configuration editing.
3. Automatically enables or disables micro-app routes based on SQLite registration state.
