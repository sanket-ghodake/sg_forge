## 1. Functional Specification

The Portal Application (`apps/src/portal`) shall operate strictly as an instantaneous Single Page Application (SPA):

1. Navigation between workspaces, apps, and settings shall utilize client-side history state manipulation (`history.pushState`) without triggering hard browser reloads.
2. Active tab states and view models shall be preserved across internal transitions.
3. Fluid responsiveness down to 320px viewport shall maintain zero horizontal page overflow.
