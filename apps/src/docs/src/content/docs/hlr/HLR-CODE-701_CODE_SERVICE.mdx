## 1. Functional Specification

The Forge Code microservice (`forge-apps/code`) shall provide cloud code editing:

1. Runs as an autonomous service on port 8088 (`/apps/code`).
2. Enforces strict chroot/sandboxing: file reads and writes are restricted to the designated workspace directory with directory traversal (`../`) prevention.
3. Provides syntax highlighting and code editing via embedded Monaco / VS Code components.
4. Manages dedicated SQLite storage in `forge-apps/code/data/code.db`.
