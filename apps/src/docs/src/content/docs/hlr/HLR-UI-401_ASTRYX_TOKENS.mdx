## 1. Functional Specification

The Astryx UI System (`@forge/ui/tokens`) shall provide immutable design token definitions:

1. Root CSS variables (`--forge-bg-root`, `--forge-bg-surface`, `--forge-bg-card`, `--forge-border`, `--forge-primary`, `--forge-accent`, `--forge-text-main`, `--forge-text-muted`).
2. High-contrast, WCAG 2.1 AA accessible color palettes with minimum 4.5:1 contrast ratios.
3. Glassmorphic surface elevations (`backdrop-filter: blur(16px)`).
4. Custom slim Astryx scrollbars eliminating OS-native thick scrollbar gutters.
