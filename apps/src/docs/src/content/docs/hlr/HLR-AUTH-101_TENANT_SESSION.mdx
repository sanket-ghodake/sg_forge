## 1. Specification

The Identity & Auth Service (`apps/src/auth`) shall authenticate incoming requests, issue HMAC-SHA256 signed JWT session cookies, enforce sliding inactivity windows (clamped between 300s and 604,800s), and inject verified `X-Tenant-Org` and `X-User-Id` headers into upstream requests.
