## 1. Functional Specification

The Developer Dashboard (`apps/src/dev-dashboard`) shall monitor all platform microservices in real time:

1. Probes `/health` (liveness) and `/ready` (readiness) endpoints across all registered services.
2. Displays an interactive live ping matrix with latency percentiles ($p_{50}, p_{95}, p_{99}$).
3. Captures real client IP addresses, machine hardware profiles, and offline geolocation.
4. Aggregates 1 year of continuous time-series rollups with sub-5ms query response times.
5. Correlates Docker container status and SQLite file sizes.
6. Alerts on service degradation using Astryx glassmorphic warning indicators.
