## 1. Functional Specification

The Client State Engine (`@forge/ui/browser-state`) shall manage browser state without Flash of Unstyled Content (FOUC):

1. Generates synchronous `<head>` script restoring active theme and sidebar collapse state before body rendering.
2. Manages versioned local state stores (`createStateStore`) with automated migration callbacks.
3. Synchronizes filter parameters with URL query parameters using `window.history.replaceState`.
4. Gracefully falls back to memory storage in sandboxed or cookie-restricted browser contexts.
