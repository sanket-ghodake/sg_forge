## 1. Functional Specification

The Logger engine (`@forge/sdk/logger`) shall output structured JSON logs matching Enterprise SRE observability standards:

1. Every log entry includes: `timestamp` (RFC 3339 UTC), `level` (`debug`, `info`, `warn`, `error`), `service`, `msg`, and `traceId`.
2. Implements recursive deep redaction (`redactSensitiveData`) neutralizing passwords, tokens, bearer headers, and credit card numbers.
3. Provides a browser console bridge (`initBrowserLogBridge`) syncing client-side telemetry to server endpoints without leaking credentials.
