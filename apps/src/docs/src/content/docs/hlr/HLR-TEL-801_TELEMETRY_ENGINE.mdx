## 1. Functional Specification

The Forge Telemetry service (`forge-apps/telemetry`) shall collect platform operational metrics:

1. Runs as an autonomous service on port 8087 (`/apps/telemetry`).
2. Collects CPU, memory, event loop latency, and request durations across registered microservices.
3. Implements rolling timeseries metric rotation: retains up to 5MB of historical samples in `telemetry.db` before pruning oldest records.
4. Exposes `/health` and `/ready` probes reporting system load.
