## 1. Functional Specification

The Central Auth service (`apps/src/auth`) shall enforce strict Role-Based Access Control across all authenticated routes. The role hierarchy is strictly defined as:

`admin` ≻ `engineer` ≻ `viewer`

1. **Admin (`admin`)**: Unrestricted access to tenant settings, API key issuance, user provisioning, and micro-app deployment.
2. **Engineer (`engineer`)**: Full access to developer dashboard, SDK playgrounds, telemetry metrics, and code services.
3. **Viewer (`viewer`)**: Read-only access to portal canvas, workspaces, and published documents.
