## 1. Functional Specification

The Developer Hub (`apps/src/dev-hub`) shall provide an interactive developer workspace:

1. Renders OpenAPI 3.1 endpoint documentation with live parameter schemas and RFC 7807 problem matrix.
2. Provides a 1-click JWT token minter with preset roles (`admin`, `engineer`, `viewer`) for rapid local testing.
3. Generates polyglot API request snippets in cURL, TypeScript, Python, and Go.
4. Simulates air-gapped API requests against running platform microservices.
