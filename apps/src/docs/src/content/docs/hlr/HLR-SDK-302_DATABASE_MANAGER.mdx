## 1. Functional Specification

The Database Manager module (`@forge/sdk/database`) shall manage hermetic SQLite / libSQL database connections:

1. Resolves canonical database paths using zero-host modification rules (`apps/data/` or `forge-apps/<id>/data/`).
2. Implements connection pooling and prepared statement caching via `bun:sqlite` and `@libsql/client`.
3. Enforces write-ahead logging (`PRAGMA journal_mode = WAL`) and strict foreign key integrity (`PRAGMA foreign_keys = ON`).
4. Executes non-blocking rolling database snapshots during backup operations.
