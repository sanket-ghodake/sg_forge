## 1. Submodule Invariants

All Forge Apps in `forge-apps/*` must maintain:
1. Independent Git submodules with standalone `.git` references.
2. Independent Dockerfiles with zero monorepo dependencies.
3. Isolated local Turso SQLite databases in `data/`.
4. Dedicated 5-Tier test architectures (`test/unit`, `test/integration`, `test/security`, `test/contracts`, `test/e2e`).
5. Colocated `docs/` with high-level and low-level requirement specifications.
