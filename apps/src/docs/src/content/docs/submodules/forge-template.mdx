## 1. Template Baseline

The `forge-apps/app-template` provides a production-ready blueprint including:
* Isolated 5-Tier test suite structure.
* Standardized `AGENTS.md` and `GEMINI.md` local directives.
* Colocated `docs/hlr` and `docs/llr` documentation directories.
* Standalone `docker/Dockerfile` and `docker-compose.yml`.
