## 1. Algorithmic Specification

1. Check in-memory client pool cache for key: client:`{appId}`:`{orgId}`
2. If client exists and connection probe succeeds, return pooled client
3. Otherwise, instantiate new `createClient({ url: 'file:' + dbPath })` instance
4. Execute PRAGMA journal_mode = WAL; PRAGMA synchronous = NORMAL; PRAGMA foreign_keys = ON;
5. Store client in pool cache with 10-minute idle eviction timer

## 2. Safety & Verification Invariants

* **WAL (Write-Ahead Logging) mode must be enabled on every SQLite instance**
* **Idle connections must be safely closed after eviction timeout**
