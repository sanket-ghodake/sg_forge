## 1. Algorithmic Specification

1. Inspect HTTP request method; if mutation (POST, PUT, DELETE, PATCH), initiate origin check
2. Verify Origin header matches configured allowed domains or host header
3. If Origin is absent, fallback to Referer header host parsing
4. Set-Cookie headers must append: HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=...
5. Reject origin mismatches with HTTP 403 Forbidden RFC 7807 problem details

## 2. Safety & Verification Invariants

* **Session cookie must never omit HttpOnly and SameSite flags**
* **Mutations with mismatched Origin header must be unconditionally dropped**
