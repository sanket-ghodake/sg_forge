## 1. Algorithmic Specification

1. Intercept window.console.error, console.warn, and uncaught window.onerror events
2. Filter out benign browser extensions errors
3. Buffer captured events and dispatch batch beacon to /api/telemetry/client-logs
4. Enforce maximum batch size of 20 items and rate limit of 5 dispatches per minute
5. Correlate client events with session traceId

## 2. Safety & Verification Invariants

* **Client log bridge must not block UI rendering or network thread**
* **Sensitive form inputs and credentials must be scrubbed before transmission**
