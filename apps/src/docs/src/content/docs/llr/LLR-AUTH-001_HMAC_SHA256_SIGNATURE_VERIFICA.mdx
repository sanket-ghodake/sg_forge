## 1. Algorithmic Specification

1. Extract JWT parts into header, payload, and signature components delimited by '.'
2. Decode signature bytes using standard base64url decoding
3. Compute HMAC-SHA256 over header.payload using server JWT secret key
4. Execute crypto.timingSafeEqual or bitwise XOR accumulator comparison over signature buffers
5. Reject tokens where signature buffer lengths differ or mismatch exists with HTTP 401 Unauthorized

## 2. Safety & Verification Invariants

* **Comparison execution time must be independent of mismatched byte position (O(1) timing invariant)**
* **Zero allocation of raw secret keys to client-facing response contexts**
