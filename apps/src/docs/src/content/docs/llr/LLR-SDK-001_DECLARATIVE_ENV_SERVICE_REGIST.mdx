## 1. Algorithmic Specification

1. Iterate over process.env keys matching regex: ^APP_([A-Z0-9_]+)$
2. Parse comma/semicolon delimited service attributes: name, port, path, type, health
3. Validate port is numeric and within range [1024, 65535]
4. Ensure service ingress path begins with '/' and contains no illegal characters
5. Return frozen immutable ServiceRegistry record map

## 2. Safety & Verification Invariants

* **No hardcoded static port bindings; all microservice ports must resolve dynamically from registry**
* **Invalid service definitions must trigger immediate startup validation failure**
