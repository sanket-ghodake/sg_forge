## 1. Algorithmic Specification

1. Scan package.json and lockfile dependencies across monorepo and submodules
2. Generate CycloneDX 1.5 JSON formatted SBOM using syft or internal scanner
3. Validate every component against permissible license whitelist (MIT, Apache-2.0, BSD-3-Clause, ISC)
4. Flag viral copyleft licenses (GPL, AGPL) as critical compliance violations
5. Archive SBOM artifact in dist/sbom.json

## 2. Safety & Verification Invariants

* **Zero viral copyleft (AGPL/GPL) dependencies permitted in core or micro-app services**
* **SBOM must account for 100% of runtime and build dependencies**
