## 1. Algorithmic Specification

1. Check active log file size using fs.statSync(logPath).size
2. If size exceeds 5MB (5242880 bytes), initiate rotation cycle
3. Rename active file to `{logName}`.1; shift existing .1 to .2, up to max .5
4. Delete oldest rotated log file exceeding retention limit
5. Open new fresh log file handle and continue logging stream

## 2. Safety & Verification Invariants

* **Total disk consumption per service log directory must not exceed 25MB (5 files x 5MB)**
* **Log rotation must be atomic and cause zero lost telemetry entries**
