## 1. Algorithmic Specification

1. Execute SQLite online backup API: VACUUM INTO backup_path
2. Compress snapshot file using gzip with high compression level
3. Store archive under data/backups/`{appId}`/`{timestamp}`.db.gz
4. Prune older backups to enforce maximum retention of 7 daily and 4 weekly snapshots
5. Generate SHA-256 checksum for backup integrity verification

## 2. Safety & Verification Invariants

* **Online backup must never acquire exclusive write lock exceeding 50ms**
* **Every generated backup archive must be paired with verified SHA-256 checksum**
