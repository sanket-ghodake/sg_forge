## 1. Algorithmic Specification

1. **Individual Invitation**: Accept display name, email, job title, organizational division, reporting line manager ID, and initial IAM role.
2. **CSV Roster Parsing**: Parse RFC 4180 CSV files with flexible aliases (`display_name`, `email`, `job_title`, `department`, `manager_email`, `role`).
3. **Formula Injection Neutralization**: Strip leading formula control characters (`=`, `+`, `-`, `@`, `\t`, `\r`) from all input values before database insertion.
4. **Line Manager Hierarchy Linking**: Automatically resolve manager emails to internal user IDs and establish directional line-manager edges in `auth_employee_relationships`.
5. **Dry-Run Validation**: Support non-destructive pre-flight validation returning record counts, parsed departments, and row-level issues before commit.

## 2. Safety & Verification Invariants

* **Anti-Self-Approval Enforcement**: Managers and admins cannot approve their own requests.
* **Privilege Escalation Prevention**: Non-super_admins are strictly forbidden from assigning `roles/super_admin`.
* **Zero Host Alteration**: CLI execution strictly uses portable Bun wrapper `scripts/import-employees.ts`.
