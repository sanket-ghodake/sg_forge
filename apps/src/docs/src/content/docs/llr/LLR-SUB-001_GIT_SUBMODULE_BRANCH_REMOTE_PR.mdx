## 1. Algorithmic Specification

1. Parse .gitmodules file to extract path, url, and branch for all submodules
2. Verify submodule path exists inside forge-apps/ directory
3. Verify submodule URL points to approved organization repository
4. Execute git submodule status to verify commit sha matches recorded pointer
5. Report any detached HEAD states or untracked changes as verification error

## 2. Safety & Verification Invariants

* **All submodules must track explicit main/master branches without detached pointers**
* **Submodules must maintain zero file modifications in parent monorepo index**
