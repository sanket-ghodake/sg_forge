## 1. Algorithmic Specification

1. Render custom button container with role='combobox' and aria-expanded state
2. Render options listbox with role='listbox' and active item aria-selected indicator
3. Listen for keyboard navigation keys: ArrowUp, ArrowDown, Enter, Space, Escape
4. Update highlighted option on arrow key navigation and scroll into view if needed
5. Close dropdown when user clicks outside or presses Escape

## 2. Safety & Verification Invariants

* **Native browser unstyled select dropdowns are strictly prohibited**
* **Full keyboard navigation parity must be guaranteed for all dropdown menus**
