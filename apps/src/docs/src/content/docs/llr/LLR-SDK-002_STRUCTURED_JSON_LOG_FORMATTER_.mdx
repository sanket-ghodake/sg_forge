## 1. Algorithmic Specification

1. Assemble log payload: `{ timestamp, severity, service, traceId, message, context }`
2. Format timestamp using RFC 3339 UTC representation: new Date().toISOString()
3. Normalize log severity levels: DEBUG, INFO, WARNING, ERROR, CRITICAL
4. Pass context object through recursive PII redaction filter
5. Output formatted single-line JSON string to process.stdout or process.stderr

## 2. Safety & Verification Invariants

* **Each log record must be emitted as strictly one single JSON line (zero multi-line breaks)**
* **Timestamp must strictly conform to ISO 8601 / RFC 3339 format**
