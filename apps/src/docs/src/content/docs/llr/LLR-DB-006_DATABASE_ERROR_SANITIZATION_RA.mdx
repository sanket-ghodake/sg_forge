## 1. Algorithmic Specification

1. Catch database exception during repository execution
2. Log full raw error details (query string, parameters, stack) to internal SRE logger
3. Map internal error codes (e.g. SQLITE_CONSTRAINT) to generic RFC 7807 problem details
4. Replace error detail with safe generic text: 'A database constraint error occurred.'
5. Return sanitized problem response with traceId for telemetry lookup

## 2. Safety & Verification Invariants

* **Raw SQL statements, table names, and column identifiers must never appear in HTTP response bodies**
* **Internal stack traces must be suppressed in all non-local development environments**
