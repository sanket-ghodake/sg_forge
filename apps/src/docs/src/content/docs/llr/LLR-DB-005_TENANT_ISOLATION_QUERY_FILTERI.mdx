## 1. Algorithmic Specification

1. Receive query request with caller's authenticated org_id
2. Verify query AST or Drizzle condition contains eq(schema.table.orgId, orgId)
3. If condition is absent on multi-tenant table, raise TenantScopingException
4. Execute parameterized query with org_id strictly bound as SQL parameter
5. Assert query result set contains zero records where record.org_id != orgId

## 2. Safety & Verification Invariants

* **Cross-tenant data exposure constitutes a Critical (Severity 1) safety violation**
* **Parameterized bindings must be used exclusively (zero string interpolation)**
