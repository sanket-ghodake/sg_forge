## 1. Algorithmic Specification

1. Define sensitive key blacklist: password, secret, token, authorization, cookie, creditCard, ssn
2. Traverse input object recursively up to maximum depth of 10 levels
3. If object key matches sensitive blacklist (case-insensitive), replace value with '[REDACTED]'
4. Scan string values against regex patterns for JWT tokens, bearer headers, and private keys
5. Replace detected sensitive substrings with '[REDACTED_SECRET]'

## 2. Safety & Verification Invariants

* **Sensitive credentials must never appear in raw plaintext in any log sink**
* **Recursion depth must be capped at 10 levels to prevent stack overflow on circular structures**
