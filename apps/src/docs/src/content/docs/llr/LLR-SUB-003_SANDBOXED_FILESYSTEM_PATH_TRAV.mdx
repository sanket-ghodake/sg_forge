## 1. Algorithmic Specification

1. Receive target file path relative to workspace root
2. Resolve absolute normalized canonical path using path.resolve() and fs.realpathSync()
3. Assert resolved canonical path starts with canonical workspace jail directory path
4. Verify path contains no null bytes (%00) or encoded traversal sequences
5. Raise SecurityTraversalException if path attempts jail escape

## 2. Safety & Verification Invariants

* **Arbitrary filesystem read/write outside workspace boundary constitutes Severity 1 vulnerability**
* **Symlinks pointing outside sandbox jail must be unconditionally rejected**
