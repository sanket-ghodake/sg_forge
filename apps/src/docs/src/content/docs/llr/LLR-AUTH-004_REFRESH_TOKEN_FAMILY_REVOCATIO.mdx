## 1. Algorithmic Specification

1. Lookup incoming refreshTokenHash in the token family database table
2. If record is marked as already consumed (revoked = true), trigger security alarm
3. Immediately execute UPDATE tokens SET revoked = 1 WHERE family_id = target_family_id
4. Clear all active authentication cookies and return RFC 7807 problem response with code AUTH_TOKEN_REPLAY

## 2. Safety & Verification Invariants

* **A token replay attempt must invalidate all active child and sibling tokens within the same family**
* **Event must log structured audit entry with traceId and remote IP**
