## 1. Algorithmic Specification

1. Acquire migration lock via dedicated __drizzle_migrations lock table record
2. Scan migrations folder for ordered SQL migration files (.sql)
3. Compare file hashes against applied migrations in __drizzle_migrations
4. Execute pending migration scripts inside an atomic database transaction
5. Record applied timestamp and release migration lock

## 2. Safety & Verification Invariants

* **Migrations must execute in strictly ascending chronological order**
* **Failed migrations must automatically rollback transaction and retain error trace**
