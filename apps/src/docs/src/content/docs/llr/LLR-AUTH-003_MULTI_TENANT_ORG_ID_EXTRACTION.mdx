## 1. Algorithmic Specification

1. Extract verified user claims from authenticated session state
2. Assert org_id conforms to canonical alphanumeric regex: ^[a-z0-9_-]`{3,64}`$
3. Append x-forge-org-id and x-forge-user-id headers to upstream request pipeline
4. Enforce strip of any client-supplied x-forge-* headers before proxy forwarding

## 2. Safety & Verification Invariants

* **Downstream services must never accept untrusted client-supplied tenant headers**
* **Every mutation query must resolve org_id from the authenticated header context**
