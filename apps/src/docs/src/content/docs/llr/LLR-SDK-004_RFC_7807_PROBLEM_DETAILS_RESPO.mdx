## 1. Algorithmic Specification

1. Generate unique traceId (UUIDv4) at the entry of createSafeHandler wrapper
2. Execute wrapped route handler inside try/catch boundary
3. On uncaught exception, log structured error record with traceId and stack
4. Construct RFC 7807 payload: `{ type, title, status: 500, detail, instance, traceId }`
5. Set Response header 'Content-Type: application/problem+json' and return HTTP response

## 2. Safety & Verification Invariants

* **All API errors must return application/problem+json conforming to RFC 7807**
* **Every error response must carry an immutable traceId matching the SRE log sink**
