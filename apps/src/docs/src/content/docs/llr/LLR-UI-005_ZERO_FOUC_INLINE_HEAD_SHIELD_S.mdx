## 1. Algorithmic Specification

1. Generate minified self-executing JavaScript snippet for direct insertion into HTML head
2. Read active theme and preferences from localStorage or system prefers-color-scheme
3. Immediately apply data-theme and styling classes to document.documentElement before first paint
4. Assert script execution time is &lt; 5ms

## 2. Safety & Verification Invariants

* **Theme initialization must execute synchronously before body rendering to eliminate visual flicker**
* **Script size must remain &le; 1KB uncompressed**
