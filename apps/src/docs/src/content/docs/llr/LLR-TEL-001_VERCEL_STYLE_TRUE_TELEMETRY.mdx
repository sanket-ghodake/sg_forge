## 1. Algorithmic Specification

1. **Client IP Extraction & Offline Geolocation**:
   - Extract real client IP from gateway reverse-proxy headers (`X-Real-IP`, `X-Forwarded-For`).
   - Classify IP subnet (Loopback, RFC 1918 Private, Public IPv4/IPv6) without outbound network calls.
   - Resolve country code, country name, and flag emoji via deterministic air-gapped subnet dictionary.
2. **Machine & User-Agent Parsing**:
   - Parse client Operating System (macOS, Windows, Linux, iOS, Android), Browser (Chrome, Safari, Firefox, Edge), CPU architecture (`arm64`, `x86_64`), and device category (`Desktop`, `Mobile`, `Tablet`, `Bot`).
3. **3-Tier Traffic Classification & Probe Exclusion (Council Decision 2026-09-13)**:
   - Automated cluster liveness and UI polling requests (`/health`, `/livez`, `/readyz`, `/api/services`, `/api/overview/stats`, `/api/apps`) are classified as `probe`.
   - Internal service-to-service calls (loopback / private network with toolchain UAs) are classified as `mesh`.
   - Real interactive human visitors are classified as `user` and serve as the **default telemetry view**, guaranteeing unpolluted latency percentiles (p50/p90/p99) and genuine unique visitor counts.
4. **Continuous Request Telemetry Pipeline**:
   - Non-blocking asynchronous event capture on every request wrapped in `@forge/sdk/createSafeHandler`.
   - Client-side Web Vitals and screen hardware specs collected via `initAppTelemetry()`.
5. **1-Year Historical Aggregation & Rollups**:
   - Real-time events stored in `traffic_events` with auto-pruning after retention window.
   - Continuous daily rollup compaction into `telemetry_daily_rollups` with partitioned metric counts (`user_requests`, `mesh_requests`, `probe_requests`) enabling `<5ms` multi-month/1-year queries.

## 3. Safety & Verification Invariants

* **Zero Outbound Egress**: Geolocation and machine intelligence must operate 100% offline within `core-airgap-net`.
* **Zero Dummy Data in Live Pipeline**: All live requests must capture real IPs, real user agents, and real execution latencies.
* **Isolated Traffic Scopes**: Liveness poll loops must never corrupt real visitor statistics or latency SLO calculations.
* **500-Line Soft Cap**: Storage, controller, and UI modules must stay within cohesive modular boundaries ($\le 500$ lines).
