## 1. Algorithmic Specification

1. Construct rate limiter key from client IP address and target endpoint: rl:auth:`{ip}`
2. Read current attempt count within rolling window of 60 seconds
3. If attempts exceed MAX_LOGIN_ATTEMPTS (default 5), reject request with HTTP 429 Too Many Requests
4. Return Retry-After header with remaining seconds until window reset
5. Reset counter upon successful authentication completion

## 2. Safety & Verification Invariants

* **Maximum allowed failed login attempts before block: 5 attempts per 60 seconds**
* **Retry-After header must accurately reflect remaining cooldown seconds**
