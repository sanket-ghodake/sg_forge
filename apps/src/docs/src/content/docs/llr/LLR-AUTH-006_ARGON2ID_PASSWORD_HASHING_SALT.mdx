## 1. Algorithmic Specification

1. Generate 16-byte cryptographically secure random salt using crypto.randomBytes(16)
2. Configure Argon2id parameters: memoryCost = 65536 KB (64MB), timeCost = 3 iterations, parallelism = 1
3. Compute derived hash key of 32 bytes output length
4. Format serialized string: $argon2id$v=19$m=65536,t=3,p=1$`{salt}`$`{hash}`
5. Verify passwords via constant-time verification routines

## 2. Safety & Verification Invariants

* **Argon2id memory cost must be >= 64MB for all production credentials**
* **Plaintext passwords must be overwritten in memory after hashing**
