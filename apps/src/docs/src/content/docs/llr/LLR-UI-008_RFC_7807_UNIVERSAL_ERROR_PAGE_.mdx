## 1. Algorithmic Specification

1. Receive RFC 7807 problem object: `{ type, title, status, detail, instance, traceId }`
2. Render Astryx glassmorphic card with status badge and user-friendly explanation
3. Display copyable Trace ID pill for fast SRE log correlation
4. Provide 'Return to Dashboard' and 'Retry' recovery action buttons
5. Never render internal raw stack traces or SQL snippets

## 2. Safety & Verification Invariants

* **Error UI must be fully responsive across mobile (320px) to desktop displays**
* **Trace ID must always be visible to end users for troubleshooting support**
