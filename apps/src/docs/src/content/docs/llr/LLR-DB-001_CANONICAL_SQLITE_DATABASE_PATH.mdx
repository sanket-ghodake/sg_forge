## 1. Algorithmic Specification

1. Receive appId and optional tenant orgId parameter
2. Assert appId conforms to safe alphanumeric identifier format
3. Construct target path under data/db/`{appId}`.db or data/tenants/`{orgId}`/`{appId}`.db
4. Validate resolved absolute path resides strictly inside REPO_ROOT/data/ boundary
5. Create parent directories with 0700 permissions if not already present

## 2. Safety & Verification Invariants

* **Resolved database path must never contain directory traversal sequences (../)**
* **Permissions on SQLite database files must restrict access to process owner**
