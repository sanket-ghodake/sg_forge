## 2. Invariants & Security Boundaries

### Zone A: Core Air-Gap Network (`core-airgap-net`)
1. **Zero Outbound Sockets**: Configured with `internal: true`. Docker blocks all default gateway packet routing for member containers.
2. **Inbound Only via Reverse Proxy**: The only ingress point is the Caddy Gateway container, which mediates external client requests.
3. **Internal Microservices**:
   - `portal` (Port 3001)
   - `auth` (Port 3004)
   - `dev-dashboard` (Port 3002)
4. **Supply Chain Defense**: Even if an attacker injects a malicious payload into an internal dependency, the payload cannot reach an external command-and-control server or leak tokens.

### Zone B: Autonomous Forge Apps Network (`forge-apps-net`)
1. **Autonomous Egress Governance**: Forge apps (such as `forge-apps/code`) live in their own network partition.
2. **Decoupled Lifecycle**: Submodules can interact with approved external developer webhooks or APIs according to their own local configurations.
3. **Zero Inward Traversal**: Submodules have no routing access to `core-airgap-net` internal databases or services.
