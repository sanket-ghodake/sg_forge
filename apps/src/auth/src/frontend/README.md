# 🎨 Auth Frontend Layer (`@forge/auth/frontend`)

Astryx user interface for Central Authentication, Login, and Password Lifecycle Management.

## 🚀 Views
* **`login-view.ts`**: White-labeled corporate login page with interactive test persona selector for instant developer testing.
* **`set-password-view.ts`**: ASVS 5.0 password configuration screen with live complexity and entropy validation.
* **`branding.ts`**: Resolves brand name, logo, and tagline dynamically from `.env`.
