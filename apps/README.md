# 🏢 Apps Directory (`apps/`)

Core platform services, shared libraries, and test suites for the SG Forge enterprise platform.

---

## 📁 Subdirectory Layout

* **[`src/`](apps/src/)**: Platform services & shared monorepo packages (`landing`, `auth`, `portal`, `dev-dashboard`, `dev-hub`, `sdk`, `ui`, `types`).
* **[`test/`](apps/test/)**: Unified 5-Tier test suites (unit, integration, e2e, contract, security).
