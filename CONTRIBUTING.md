# Contributing to SG Forge

Thank you for your interest in contributing to SG Forge! To protect all contributors, users, and the open-source community from copyright and intellectual property disputes, all contributions must strictly adhere to the standards below.

## ✍️ How to Sign Your Commits

Every commit submitted via Pull Request must include a `Signed-off-by:` trailer matching your Git author name and email.

You can automatically add this line to your commits using Git's `-s` / `--signoff` flag:

```bash
git commit -s -m "feat(scope): descriptive summary of changes"
```

This will automatically append the legal certification trailer to your commit message:

```
Signed-off-by: Jane Developer <jane@example.com>
```

PRs containing unsigned commits or code originating from an employer's proprietary codebase without written authorization cannot be accepted.
